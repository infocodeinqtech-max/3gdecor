
# 3G Decorative Group — Frontend

Luxury interior design website built from the [Figma design](https://www.figma.com/design/ufQr1V4rA4dnz1Z17u3VHF/Luxury-Interior-Design-Homepage).

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion / Motion
- React Router

## Pages

| Route | Page |
|-------|------|
| `/` | Homepage |
| `/about` | About Us |
| `/services` | Services |
| `/contact` | Contact |
| `/privacy-policy` | Privacy Policy |

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`. The app is configured with base path `/3gdeco/tmp_2/` for Laragon deployment.
